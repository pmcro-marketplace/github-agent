# Native runtime and lifecycle

The registry is assets/native-capabilities.json. The actual .NET program
discovers the designated definition and exposes bound skills on its live
A2A Agent Card. AIAgent invokes a five-step MAF workflow for every request.
AGT run middleware emits actual governance events. AG-UI streams frames
as text deltas; A2A carries the same result.

Plan permits exact scoped read functions and two host-approved HTTPS POST functions.
Make performs HTTPS GET or a single approved POST.
Check independently fetches and matches the repository identity and, for a
specific run, run identity. Reflect returns acceptance or corrective context.
No workflow run success is inferred solely from an empty list or HTTP 200.

The existing github plugin still declares additional intended functions
from upstream. A declared function is not a native binding. The native card
advertises three read and two conditional write bindings. Remote writes require explicit
authority, credentials and the provider contract. See write-authorization.md.
Function-call middleware
and independent model execution are not claimed.
